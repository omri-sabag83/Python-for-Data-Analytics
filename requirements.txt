#   cd 03_Project && make run

#   The analysis is driven by 3 parameters, all set in one file - 03_Project/config.py.

#     - SELECTED_COUNTRY   the job market the analysis focuses on
#     - BENCHMARK_COUNTRY  a larger market shown alongside it for comparison
#     - MIN_SKILL_COUNT    minimum postings a skill needs before its median salary is reported
